原始 GLB 保留不改。

实际结构与动画需求
原模型是一个合并网格：14,102 个导入顶点、13,015 个三角面、两张贴图；无骨骼、无动画。
船为开口船舱，包含三道横向座板、前后端板、下凹舱底。没有可独立控制的桨、舵或门。
项目 HabitatMainStory.Chapter.cs 通过整船 Transform 航行、上下浮动约 ±0.035m、侧倾约 ±2°。本成品保持静态，不添加无用途骨骼或重复烘焙航行动画。

尺寸、朝向和原点
源 Blender 坐标尺寸：长 X=1.902579，宽 Y=0.775769，高 Z=0.839565。
成品按源比例统一放大至长 3.000000m，宽约 1.223238m，总高约 1.323832m（含两端柱）。没有拉宽、压高或重塑船体。
比例约 1.576807，精确值在报告中。
源文件没有船首语义；本次约定把原始 -X 方向、艏柱较高的一端作为船首，转为成品 +Z 前向，以符合项目船前向要求。
成品 glTF 坐标：+Y 向上、+Z 船首、+X 右舷。Blender 中同一资产为 +Z 向上、-Y 船首。
FBX 使用 Forward=-Z、Up=Y 的常规导出设置，导入器负责坐标转换；勿再次重复手动旋转。
成品根 WoodenBoat_Root 位于船体平面包围盒中心及建议水线高度。

水线是视觉建议，不是浮力计算
通过船外侧射线命中、原 UV 插值与原底色采样，蓝色船底涂装上沿在源 Z=-0.29 至 -0.31；取中值 -0.30 作为成品 Y=0。
成品最低点在水线下约 0.191114m。载荷、排水量和真实吃水未计算。
舱底低于建议水线。若项目使用未经船体排除/遮罩的连续水面，水面会穿进开口船舱；接入时须处理船内水体遮罩或按美术需求调整整船高度。本次未修改水体、Unity 场景或船体几何。

已导出的四个挂点
以下均为成品 glTF/项目约定坐标 (X, Y, Z)，单位按 3m 船长准备；实际导入后也可直接读取同名子 Transform。

Seat_Center_Surface
  (0.000140, 0.348508, -0.040063)
  中央座板上表面中心。它是座面接触参考，不是已校准的 Player 髋部或根节点位置。

Footwell_Aft_Surface
  (0.000140, -0.154495, -0.316004)
  中央与后侧座板之间的舱底局部落脚参考。它位于建议水线下，不是登船平台。

Boarding_Port_Rim
  (-0.520207, 0.530182, -0.316004)
  左舷船沿表面参考，须跨越船沿才能进入船舱；不是宽阔平坦落地点。

Boarding_Starboard_Rim
  (0.520486, 0.529502, -0.316004)
  右舷船沿表面参考，含义同上。

四点均由原网格垂直首命中射线得到，不是根据图片猜出的高度。挂点是静态 Empty/Transform，随 WoodenBoat_Root 移动，无需骨骼。

站立区域检查
座板间舱底采样区域约宽 0.441506m、长 0.283825m，25 点表面高度约 Y=-0.155955 至 -0.105210m。
该小区域含木板缝、局部高度变化及接近竖直的接缝面，不能视为完整平坦甲板，也未认证玩家胶囊的通行净空。
当前模型适合使用明确乘坐/固定落脚姿态；如果后续要求自由走动，应在项目中为舱底、座板、船沿分别设计碰撞和移动约束。本次未添加 Collider。

与当前项目的接入差异
项目旧代码用“船根位置 + 0.71Y”定位 Player，没有读取本模型挂点。该偏移不得直接沿用为新模型的座面高度。
以座面接触点比较，旧 +0.71 比本模型中央座面 +0.348508 高约 0.361492m；Player 根还必须加上实际 Ride 动画对应的姿态偏移。
后续接入应读取 Seat_Center_Surface，并按当前角色的根/髋部位置校准偏移；登船路径可用相应舷侧挂点作参考。不要为保留旧偏移而把船体拉高或扭曲。
现有停泊船若与码头合并在同一网格中，不应直接用本独立船覆盖整个码头。
本次只交付资产、测量与接入建议，未修改 Unity 代码、场景、角色或现有码头。
