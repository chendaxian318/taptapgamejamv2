01 / QUIET OBSERVATORY

A · 轻量海岛观察台

采用方案 · 4.70 / 5

纸白、小面板、深绿选中态。常驻信息沿边缘分组，中央留给观察和操作。

布局示意 · 1600 × 900 参考尺寸 · 右侧展示“选中地块”状态，默认收起
#F8FAF7#173D3A#61756F#E8EFEB#D87558#245D50
适合当前项目

保留清晰的中文工具名称与目标说明。居民、日志、观察卡按需展开，减轻周边的卡片密度。

实施重点

顶部约 64 高，侧栏 270～280 宽，工具区约 640 × 76。正文 15～16，辅助 12～13，圆角 6～8。

02 / FIELD JOURNAL

B · 岛屿标本手帐

备选 · 3.94 / 5

把任务与居民集合成一本固定手帐，适合阅读和教学，纸质感更浓。

布局示意 · 固定手帐让信息集中，也占用更多常驻空间
优点

自然主题明确，任务与居民关系容易阅读，可扩展章节、物种与观察记录。

未选原因

左侧固定面板更重。纸边、页签、纹理需要更多美术工作，现阶段收益低于精简布局。

03 / ECOLOGY INSTRUMENT

C · 透明生态仪表

备选 · 4.18 / 5

极少的底色与图标工具带，把绝大部分画面交还海岛，偏向熟练玩家。

布局示意 · 轻文字与透明底的对比需随场景检查
优点

常驻面积最小，视觉轻，可作为未来的纯观察或截图模式。

未选原因

海面高光、地形与动物可能影响对比；纯图标对初次体验者不够明确，需要额外解释。

DECISION / 自主评估

采用 A：简洁，也能直接上手。
