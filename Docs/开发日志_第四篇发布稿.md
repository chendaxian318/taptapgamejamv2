# 开发日志 04 修正操作反馈并打通主线试玩

上一篇日志中，我们记录了移动判定提前、动作反馈不足和流程引导不够清楚等问题。接下来的开发围绕这些反馈展开：让人物动作与操作结果对应起来，再把岛屿解谜、捕捞收获和返港补给串成一段能够连续游玩的旅程。目前，《栖屿》已经完成五个主线关卡的流程串联，并制作了包含新版规则与剧情 CG 的 Windows 试玩包。

我们首先处理了人物还没走到目标格，程序就已经判定到达的问题。现在，人物和被推拉的箱子全部到位、落地动作结束后，才确认这一步操作，并记录可撤销的结果。动作进行时，下一次操作需要等待，避免连续输入提前触发交互。主角比例、步行和推拉速度也随之调整，配合伸臂推箱、后倾拉箱与落地缓冲，让动作更容易辨认。

打捞与钓鱼也沿用了同样的处理原则。此前计划采用的黑屏打捞，已经改成可见的探网、箱子出水、人物后退和落箱收网过程；钓鱼则补上抛竿、收线和渔获入篓的连续动作。箱子放稳、渔获落袋之后，操作结果才正式生效。调整中还遇到了收鱼时人物追着渔获转向、身体来回抽动的问题，最终让人物保持抛竿朝向，鱼线单独跟随渔获，改善了动作衔接。

关卡方面，新的五关主线逐步引入风箱、竹排、潮汐、磁铁和发射器等机制，空间路线与动物需求需要一起考虑。金鱼需要封闭水域，水母需要与外海连通，寄居蟹则关注岸地和附近的水生邻居。整关完成要求所有在场动物同时适居，因此一次推箱或地形调整，既要帮助当前目标，也要留意其他动物的生活条件。

![第四关阶段实拍](D:/chatgptproject/taptapgamejam/HabitatIsland3D/Verification/latest-cg-campaign/player-visible-specialties/level-8-player.png)

*第四关完成后的画面：箱子、竹排和不同高度的地块共同参与路线组织，关卡目标是让岛上动物同时适居。*

港口流程也重新整理为独立的家园空间。玩家从码头出发前往各岛，返航后交付委托、出售收获，再购买下一轮改造所需的工具。岛上已经调整的地形和动物状态会保留；个别动物达到适居条件后，也可以先收获、回港补给，再返回尚未完成的岛。这样，捕捞、繁衍、交易和采购便能接入实际解谜过程，物资的来源与消耗也有了连续记录。

![独立家园港口实拍](D:/chatgptproject/taptapgamejam/HabitatIsland3D/Verification/latest-cg-campaign/player-visible-specialties/level-11-overview.png)

*家、商店和小船集中在独立港口，承接出航、交易与休息。各关岛屿通过短渡口往返。*

随着流程逐渐连贯，美术与声音也继续补齐。金鱼、寄居蟹和水母陆续接入三维动画模型，鱼竿、铲子、贝壳风箱与背篓开始配合实际操作显示。脚步、推拉、收获和交易加入了对应音效，帮助玩家确认动作结果。主菜单、背包、商店和选关等界面逐步换上正式素材，三段剧情 CG 分别接入新游戏、第一关完成和回家休息的节点。

试玩包检查中，我们发现原本能在编辑器播放的 CG，在独立程序里出现了音轨兼容问题。为视频制作兼容副本后，三段播放与后续剧情结算完成了复测。新版试玩包随后通过正式游戏控制器驱动的自动化验证，从零金币、无装备的新游戏连续完成五关主线、返航结局及存读档；购买和工具消耗使用实际游戏收益，重复繁衍的等候部分采用测试加速。接下来仍需要人工试玩，检查谜题难度、等待节奏和提示是否清楚。

最近接入的日景与暖色双封面，则让游戏每次启动时随机呈现一种海岛氛围，同次运行返回菜单时保持不变。确认窗口和剧情对话也换上了已交付的原版美术素材。这部分已经在编辑器中检查，尚未合入现有试玩包，后续会随新构建继续复核。下一阶段，我们会结合试玩反馈，继续调整引导、动作节奏与界面可读性，让玩家更容易理解自己的每一步操作如何改变这座小岛。
