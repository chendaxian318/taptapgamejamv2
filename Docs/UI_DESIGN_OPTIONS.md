# 栖屿 · 界面改版方案

本文件记录三套布局方案与自主评估。配套 [交互对比板](UI_DESIGN_OPTIONS.html) 是界面布局草图，岛屿为示意图，不是 Unity 实机截图。

## 当前界面的主要问题

依据 `Verification/terrain-occlusion.png` 和现有 `HabitatHud.cs`：大面积米黄色卡片、加粗文字、圆角按钮共同争夺注意力；资源、暂停、实验室、状态分成多个独立大块；工具栏宽 854、高 98，六块按钮的视觉重量超过工具本身；底部整行快捷键过密。当前关卡与目标、被选地块、当前工具应是三个主要阅读层级，品牌、日志和实验参数应次于它们。

改版保留全部玩法入口。居民手册、日志及详细观察采用按需展开；全量快捷键放入帮助，常驻区域仅保留高频操作。所有方案均以 1600 × 900 为参考分辨率。

## A · 轻量海岛观察台（采用）

**方向：** 纸白信息面板、深海绿文字、轻分隔线。小尺寸浮动控件沿屏幕边缘分组，中心岛屿保留完整操作空间。珊瑚色只承担提醒与极少数强调，不把所有按钮做成彩色卡片。

| 区域 | 布局与信息层级 |
| --- | --- |
| 顶部 | 64 高的紧凑信息区。品牌和关卡在左，资源和观察控制在右；状态作为辅助文字或小标识，取消独立中央大胶囊。 |
| 左侧 | 270～280 宽目标卡；标题 18、正文 15～16、进度 13。目标紧邻关卡，居民手册入口在其下，手册默认收起。 |
| 右侧 | 仅选择地格时出现约 276 宽观察面板。地块/生物名为主，条件和高度其次，执行工具为单一主按钮。 |
| 底部 | 约 640 × 76 的紧凑工具区，五个工具保持数字键提示。当前工具深绿填充、白字；其他工具浅色或透明。补给入口分组清楚。 |
| 次级操作 | 手持物与撤销保持临近；日志为轻量入口。重开、范围、帮助、实验室仍有可见入口。 |
| 反馈 | 短时消息贴近工具区，限制高度；成功、暂停、受惊用文案和颜色共同表达。 |

**统一设计变量：**

| 用途 | 色值 |
| --- | --- |
| 面板纸白 | `#F8FAF7` |
| 正文深海绿 | `#173D3A` |
| 次要文字 | `#61756F` |
| 次级按钮/分区 | `#E8EFEB` |
| 珊瑚强调 | `#D87558` |
| 当前工具/主按钮 | `#245D50` |

字体保持现有中文字体，减少全局加粗。品牌 28～30；弹窗标题 26～28；面板标题 18；正文 15～16；辅助 12～13。圆角 6～8，面板内边距 16～20，控件间距以 8 的倍数为主。按钮高度至少 36～40；不用大范围阴影或材质纹理。正文有纸白底承托，避免依赖海面背景来获得对比。

**弹窗：** 商店、帮助、观察设置（原实验室）、垂钓使用同一组色值和标题层级；背景轻微压暗。帮助按三个动作主题分区，删除面向开发者的节点号、临时模型说明等产品界面文字，完整快捷键仍可查。设置的数值行用细线或浅底分组；商店将物品名称与价格形成清晰对应；关闭/返回操作固定于底部。

**优势：** 改造量适中；减少常驻遮挡，同时保留新手的文字入口；颜色与海水、草地、木船自然衔接。适合当前多工具、生态规则较多的关卡原型。

## B · 岛屿标本手帐

**方向：** 左侧固定纵向野外手帐，目标、居民和进度集中；右上为资源标签，底部工具采用细长木质/纸质页签。适合故事或教学内容较多的版本。

布局为左侧约 310 宽手帐、顶部 60 高资源组、右侧条件卡、底部约 690 × 78 页签。主色为暖白 `#F4F0E7`、炭绿 `#294941`、苔绿 `#7D9277`、陶红 `#B96F50`。标题 26、页标题 19、正文 16、注释 13。细纸边、少量横线、章节编号提供手帐感，不使用多余贴纸装饰。

**取舍：** 与自然生态主题契合度最高、任务阅读舒适；左边持续占用较大画面，居民数量增加后容易形成长列表，对当前“先看岛、再操作”的玩法不够简洁。纸张和页签细节也需要额外美术统一。

## C · 透明生态仪表

**方向：** 白色文字与极少量半透明深色薄面板，目标压缩为顶部一行，工具变为底部图标带，详细信息只在选择后出现。适合熟练玩家或截图观察模式。

布局为顶部约 56 高信息线、左侧 240 宽轻量目标提示、底部约 510 × 60 图标带、按需出现的右侧观察面板。主色为透明深绿 `#103D3D`（约 65% 不透明度）、白 `#F4FBF7`、雾绿 `#BBD4C9`、珊瑚 `#E58B6B`。品牌 24、主读数 17、正文 15、辅助 12。去除常驻装饰，只保留简洁图标、文字与短线。

**取舍：** 岛屿留白最多、轻盈直接；海面高光、淡出地形、动物轮廓会让细文字的对比不稳定。仅图标工具不利于首次体验，需要更多悬停解释和适应时间。当前项目尚不适合把所有提示降到这一程度。

## 评估与选择

以下为设计判断评分，满分 5；不是用户测试结果。改造便利度越高，表示现有 uGUI 结构越容易保持并完成。

| 方案 | 简洁度 40% | 海岛契合 25% | 操作清晰 25% | 改造便利 10% | 加权分 |
| --- | ---: | ---: | ---: | ---: | ---: |
| **A 轻量海岛观察台** | **4.8** | **4.6** | **4.7** | **4.5** | **4.70** |
| B 岛屿标本手帐 | 3.2 | 4.9 | 4.2 | 3.8 | 3.94 |
| C 透明生态仪表 | 4.9 | 3.8 | 3.7 | 3.4 | 4.18 |

采用 **A**。它比现状减少卡片面积与加粗层级，同时让目标、工具、被选地块的含义保持明确。B 保留为未来叙事手册方向；C 的留白可用于后续观察模式。

## 实机验收要点

- 默认画面、展开居民手册、选中地块、短时反馈均不遮住核心操作区；左右面板不与顶部控制和底部工具重叠。
- 当前工具有明确选中态，五种工具与补给、暂停、帮助、实验室、撤销、重开、范围、日志全部可到达。
- 长关卡目标、动物状态与规则原因不截断、不挤压按钮；帮助保存 Q/C、V、Alt 等完整说明。
- 以 1920 × 1080 和 1366 × 768 实际查看，另检查 1280 × 720 锚点布局；中文可读，弹窗完整，按钮触达正常。
- 商店、帮助、实验室与垂钓风格一致；打开关闭仍正确暂停和恢复模拟。

## 已实现与验证

2026-10-13，A 方案已实装。底部工具栏由 854×98 改为 612×76，面积减少约 44%；左侧目标卡宽 270、按需出现的右侧详情卡宽 280，顶部统一为 64 高信息栏。主动作深绿、次级动作浅灰绿、提示仅少量珊瑚色。主界面保留精简键位提示，全量基础操作放入帮助。设置内新增保存成功/读取失败短反馈，地图入口读取当前关卡列表；没有繁衍目标的地图显示“探索提示”，不显示 0/0。
