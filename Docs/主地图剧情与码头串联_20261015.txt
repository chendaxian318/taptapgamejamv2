栖屿：主地图剧情与码头串联（2026-10-15）

本次范围
按用户「那你串进去」的要求，将原独立码头原型的首日/晨光 Timeline 接入默认主地图，同时接通家、真实渔获交易与保留进度的船旅。主地图、现有主角和导入码头模型均保留；默认正式关仍为 index=4。

体验入口
打开 Assets/HabitatIsland/Scenes/HabitatIsland.unity，进入 Play。
新游戏自动播放约15.3秒：蓝天海鸟→小船归航→收网→带渔获走到商店。片段上方提供暂停/继续、跳过；空格/Esc也可暂停/继续。普通游戏操作在片段中锁定。片段结束后直接控制主地图中的原主角。
靠近商店按 E：购买物资或「交付全部渔获」。首日默认带回鱼3条、虾2只，实存于背包，只发放一次；按原有鱼8/虾5贝币出售，合计34贝币，交付后真实扣库存并记录累计交付/收入。空库存不能重复领钱。
从商店沿木栈道走到大屋门前，按 E 打开「家·休息」。选择休息后播放约5秒的实际窗台晨光，完成或跳过后只增加一天。背包、贝币、岛屿改动与居民保留，可继续自由活动；没有添加NPC或新任务奖励。
靠近小船按 E，选目的地并确认出发。已到访岛屿恢复上次地形和居民，库存、货币、天数、交付记录全程共享；再次到访不会刷新已售出的开场渔获。
设置中的「返回码头」返回当前地图的船旁，不切换独立场景、不重置地图。快捷返回和出航需先放下手中的动物/道具，避免岸边受阻时手持物无法在码头放置的死路。背包鱼虾和物资可直接带走。

暂停与存档
片段开始保存原暂停状态，结束恢复；正式地图原本开局生态暂停，因此开场后仍显示暂停，但玩家可走动和交互，空格可继续生态模拟。
存档保留当前地图、到访地图缓存、天数、背包和累计交付。仍兼容 HabitatIsland/1；旧档没有旅程字段时默认为第1天，不补发鱼虾，也不主动补播开场。
演出中禁止保存半完成状态；读取已有存档会取消演出，旧晨光不会延迟把新档天数增加。跨地图清空撤销栈，避免在别的岛撤销旧交易复制物资。
调试重置关卡/Backspace仍使用原 LoadLevel 的新建状态语义，区别于正常船旅。独立 HarborPrototype 保留作开发演示，默认主地图流程不再使用它。

主要实现
HabitatGame.Journey.cs：演出事务、家中休息、同图返回、船旅缓存、扩展存档。
HabitatMainStory.cs：复用原 Timeline 的主地图角色、镜头、海鸟、网与渔获道具、实际窗口灯光；临时资源结束后清理。
HabitatJourneyRules.cs / HabitatModel.cs：一次性开场库存、天数、共享资源、克隆与实际交付统计。
HabitatHud.Harbor.cs / HabitatHud.cs / HabitatHud.Layout.cs：家面板、附近 E 提示、交付明细、到访标记、剧情控制。
HabitatMapHarbor.cs：家/店/船最近交互、真实甲板上的安全放置。
HabitatView.cs：演出期间由Timeline控制相机与角色，结束恢复正常表现，不影响格子动作的到位提交。
HabitatDockBeatTrack.cs：共享 IHabitatDockTimelineTarget，兼容主地图和原独立原型。
主场景通过 Unity API 挂载 HabitatMainStory 并保存原有两份 Timeline 引用，没有重建场景。可复用 AgentScripts/JourneySetup.cs，要求主场景非Play且无未保存改动。
