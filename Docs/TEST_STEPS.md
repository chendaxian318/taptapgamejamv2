## 准备与操作

打开主场景 `Assets/HabitatIsland/Scenes/HabitatIsland.unity`。坐标从 1 开始。按 Tab 打开“栖居实验室”，下方按钮选择关卡；每组测试先点“恢复默认”，再关闭动物自主移动，便于固定条件。关闭面板后确认暂停状态，`.` 每次推进 1 秒；风机仍随模拟时间运行。左侧“居民手册”可展开选择物种，右下“岛屿日志”显示近期事件。

| 操作 | 输入 |
|---|---|
| 四向移动／推木箱 | WASD 或方向键；方向跟随镜头，按画面上下左右移动 |
| 选目标／执行当前工具 | 左键／E 或右键 |
| 抱起、铺土、引导、虾笼、收获／垂钓 | 1、2、3、4、5 |
| 暂停／单步／撤销／重开 | Space／`.`／Z／Backspace |
| 商店／栖居实验室／帮助／关闭弹窗 | B／Tab／F1／Esc |
| 旋转机关／转镜头／缩放 | R／Q、C 每次 90°／滚轮 |

搬运需四向相邻，铺土可选周围 3×3，钓竿引导与收获距离为 4 格。面板开启期间暂停，关闭后恢复先前状态。重开和换关保留参数；参数修改不在撤销范围内。

测试 JSON 保存关卡状态、参数和操作计数，不保存当前工具、镜头、模拟速度或撤销栈；读取后清空撤销历史并暂停。文件位于 `Application.persistentDataPath/Playtests`，需要延续实验时须另行迁移 JSON。

垂钓面板中，Space 或鼠标左键用于控条，不再切换岛屿暂停。按住时绿色区域上升，松开时下落；Esc 收竿。

## 1. 螃蟹的欢迎会：驱赶与邻居

1. 选第一关并暂停。点击寄居蟹，记录红虾造成的不安全状态。
2. 玩家初始在 `(2,3)`。选 `(3,3)` 红虾，按 `1`、`E` 抱起；选 `(2,4)` 已有虾笼格按 `E` 放下。
3. 检查寄居蟹：红虾威胁解除，水母与海星满足两种其他物种条件。
4. 推进默认 18 秒，检查寄居蟹后代数量和目标达成提示。按 Z 比较上次状态；另试抱起寄居蟹／海星，预期操作被拒绝且显示原因。

## 2. 池塘与高地实验室：地形条件

1. 选第二关，此关切入后默认暂停。分别检查金鱼的封闭池塘条件、海龟的连通高地条件。
2. 玩家在码头附近时按 B 领取一块土；走到 `(4,3)`，选 `(5,3)`，用工具 `2` 填土封住池塘缺口。
3. 返回码头再取一块土，经左侧陆地绕到 `(6,6)`，选 `(7,6)` 填土，将高度从 1 提到 2。
4. 两只目标动物应转为适居。推进 18 秒，检查首次繁衍；重开后只完成其中一项，另一项条件应继续显示缺失。

## 3. 潮汐机关原型：推箱、涨水与浮箱

1. 选第三关并暂停。从 `(2,3)` 经 `(3,3)`、`(3,4)` 到 `(3,5)`，向右走，把 `(4,5)` 木箱推到 `(5,5)` 潮汐踏板。
2. 检查水位升高 1、低地变水、水母的连通水域扩大。海龟高地应仍然有效。
3. 推进若干秒，观察风机沿朝向推动首个浮箱；也可暂停后走到浮箱上再单步，检查玩家跟随移动。
4. 重新暂停，拿走踏板上的箱子，检查水位恢复；按 Z 撤销拿取，让踏板重新受压。维持适居并推进默认 18 秒后，水母与海龟应产生后代。

## 4. 六物种生态沙盒：繁衍、收获与复现

1. 选第四关，关闭动物移动并暂停。逐只查看条件，推进 18 秒；默认布局应支持六物种首次繁衍与目标达成。
2. 持有鱼竿，在金鱼 4 格内用工具 `5` 开始垂钓。先按 Esc 取消：鱼后代与背包应保持不变，岛屿恢复先前暂停状态。
3. 再次垂钓，故意不跟随鱼，直到收线进度归零或 35 秒超时：应显示脱钩，后代仍保留，允许重试。
4. 第三次尝试，按住／松开 Space 或左键，使绿色区域持续覆盖鱼标记直到进度满。预期收取该目标当前所有后代，背包鱼数量增加且亲代仍在原格。全过程中岛屿时间应暂停。
5. 虾笼自动将红虾后代计入库存。回 `(2,3)` 码头附近按 B 出售，金币增长应为“鱼数量 ×8 + 虾数量 ×5”。拿取土壤后再买一件需手持的道具，预期被单件搬运限制拦住。
6. 按 Tab，在实验室点击“保存测试”；关闭面板并改动地形后，再打开实验室点“读取测试”。检查地形、动物、库存与参数恢复，回到小岛后仍应暂停。记录保存提示中的 JSON 路径。

## 本轮简化与反馈

金鱼使用控条垂钓小游戏，难度为测试取值；其他物种后代仍使用点击研究收获或虾笼自动捕获。虾笼暂会固定亲代并可重复捕获。本文四关是旧规则实验地图；当前另有按 FigJam 四表逐格转录的正式图，其末端宝箱完整路线、完整经济循环与最终委托仍待验证或定义，不能据旧四关通过宣称正式图通关。

当前主角使用本地 Meshy 旅行者 3D 模型与待机／行走／跑步动画，已通过 [56 项真实帧运行检查](../Verification/meshy-traveler-checks.txt)；原正背面 Sprite 保留为备用。虾已改为用户提供的静态 Meshy 3D 模型，保留原 PBR 贴图，没有骨骼或动作动画，也未执行 UniRig；已有 [16 项模型与交互检查](../Verification/meshy-shrimp-runtime-checks.txt)。水母、金鱼、寄居蟹使用原画，海龟与海星为临时几何造型，详见 [资源说明](ART_SOURCES.md)。
