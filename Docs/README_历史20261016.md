## 启动

- Unity Hub 打开项目，载入 `Assets/HabitatIsland/Scenes/HabitatIsland.unity` 后点击 Play。
- 默认 `startLevel=4`，**18×19 连续地图**。归航后与老板交谈接取委托，乘船确认出发，找到特制竿、围鱼、钓获2条琉璃鱼，到店交付200贝币并回家迎接第二天；生态暂停时仍可移动与使用工具，Space继续模拟。
- 直接打开已有场景即可；`Tools/Habitat Island/1. Create Playtest Scene` 会重新生成并保存场景，不是迁移后的启动步骤。
- 第一关主线及美术替换接口见 [第一关主线与占位](Docs/第一关主线与占位_20261016.txt)。F1中的“新手教学”仍可进入可选的“螃蟹的欢迎会”生态练习；它不是琉璃鱼委托主线。其余三座正式章节岛目前灰锁占位。

界面坐标从 **1** 开始。正式图依据四张原表逐格转录；源图零基 `(列,行)` 对应世界 `(x=列,z=18−行)`。另外保留“螃蟹的欢迎会”“池塘与高地实验室”“潮汐机关原型”“六物种生态沙盒”四套 9×9 规则实验场，旧实验关目标不套用正式图。详见 [正式关测试记录](Docs/FIGMA_LEVEL_TEST.md)。

按 Tab 打开设置，可保存、读取进度及返回码头；靠近小船按E选择目的地，再确认进入。左侧“居民手册”可展开查看六物种，工具面板内“岛屿日志”可查看近期事件；点击动物或地格打开栖居观察卡。

## 先测试这一轮

正式图优先复验出生点到潮汐、鱼竿宝箱及寄居蟹岛的已验证路线；末端宝箱完整路线和正式关完整经济循环仍待验证。下面的生态循环可在旧实验关中逐项测试，不代表正式关已完整通关。

1. 进入关卡后先暂停，点击动物与地格查看条件。记录当前不满足的条件。
2. 调整地形或搬运动物。每次只改一个变量，例如扩大池塘、隔开红虾、增加邻居或连通高地。
3. 单步推进观察变化，再恢复运行查看繁衍进度。需要隔离地形判定时，关闭动物自动移动。
4. 收取金鱼／红虾后代，去码头出售，购买并逐件搬运土壤继续改岛。
5. 用撤销和重开复验；切换关卡测试生态关系与机关组合。

## 操作

| 输入 | 功能 |
|---|---|
| WASD／方向键 | 按当前画面的上下左右移动，Q/C 旋转镜头后方向随之更新；迎着木箱走可推动 |
| Shift＋方向键 | 仅攀爬方块可向上攀高最多两层；普通地块和箱子不能向上爬 |
| 鼠标左键 | 选中地格，检查动物、地形和条件 |
| E／鼠标右键 | 使用当前工具；右键也会选中点击的地格。搬运需四向相邻，铺土可选周围 3×3，钓竿可达 4 格 |
| 1／2／3／4／5 | 切换交互／填土／引导／捕虾笼／收获或垂钓工具 |
| R | 旋转相邻道路或风机 |
| Space | 暂停／继续 |
| . | 暂停并推进 1 秒 |
| Z | 恢复上次操作或单步前的状态，并暂停 |
| Backspace | 重开当前关卡 |
| B／Tab／F1 | 渡口补给／观察设置／操作帮助 |
| Esc | 关闭弹窗，恢复打开前的暂停状态 |
| Q／C／滚轮 | 镜头向左／右旋转 90°／缩放 |
| M／Home／中键拖动 | 全图总览／回到人物／平移镜头 |
| V | 开关自动遮挡透明，默认开启；挡住后方地块或居民的上层地形渐隐，移开遮挡后恢复 |
| Alt＋鼠标点选 | 优先选择前方高层；通常点选会穿过已淡出的上层，选择后方地格 |

可抱动物、方块、船上货物共享搬运限制。携带土壤后选择近处地格使用填土；不合条件的操作会显示原因。寄居蟹和海星无法直接抱起。虾笼会让亲代停留，并自动收集该格虾的后代；本轮暂可重复使用。

用工具 `5` 对有后代的金鱼操作会进入垂钓：按住 Space 或鼠标左键抬升绿色区域，松开使其下落，持续覆盖鱼标记直到收线进度满。失败或按 Esc 收竿均保留后代；成功后收取后代，成年金鱼仍在岛上。垂钓期间岛屿模拟暂停。

弹窗打开时模拟暂停。关卡切换与重开保留测试参数；需回到基准时，在实验室点击“恢复默认”。撤销恢复地形、动物与库存状态，不撤销参数改动。

测试 JSON 保存关卡状态、测试参数和操作计数；**不保存当前工具、镜头、模拟速度或撤销栈**。读取后清空撤销历史并暂停。存档位于 `Application.persistentDataPath/Playtests`，不在工程目录内；需要延续某次实验时应单独迁移存档。

## 建议的验收记录

| 测试 | 重点观察 |
|---|---|
| 潮汐关启动引擎，扩大水母水域 | 连通水域条件何时满足；撤销后的变化 |
| 实验室关填住池塘缺口，再撤销填土 | “面积足够”与“封闭”分别判定 |
| 红虾靠近不同高度的动物 | 驱赶是否只影响同高度目标 |
| 建立海龟高地后再让红虾靠近 | 庇护范围、有效条件、解除后的变化 |
| 给寄居蟹增加两种其他物种 | 统计的是物种数而非个体数 |
| 连出两格岸地，并给海星友好邻居 | 岸地连通、安全、邻居条件分别检查 |
| 推箱、堆土、旋转道路、风机吹漂浮块、压下潮汐引擎 | 机关是否改变真实可达性与栖居判定 |
| 收取后代并交易 | 亲代保留、收入扣费、单件搬运的循环是否顺畅 |

反馈时请记录：关卡、动物／格子坐标、参数、操作顺序、预期结果、实际结果。优先用暂停与单步复现，避免自动移动造成条件变化后难以定位。测试面板可以保存当前状态为 JSON，并读取最近一次记录；保存结果会在设置面板内显示。
