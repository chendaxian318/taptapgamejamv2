UI 第二批接入与版式纠正（2026-10-18）

用户要求
先接现有草图 UI，后续用高清透明部件替换。用户指出第一版背包上下标签截断、角色黑底，以及多页布局偏离设计。不能把截图粗裁和自行改版称为完成原稿还原。

本轮修改
1. 背包：撤掉错误的 TOOL / CREATURE 截图片段，改回左侧大角色、TOOL / CREATURE / ITEM 三层结构；角色用工程已存的二维 HeroFront 原画，运行时处理白底，源图未覆盖。工具四项一页；收纳道具五格一页，真实数量和库存不变。
2. 商店：左侧老板、BUY / SOLD、对话区，右侧三行四列货架。实际已有八类操作，剩余四格空置；不冒用设计稿中的 888 余额、150B 单价或示例数量。当前老板仍用已交 3D 模型的透明预览。
3. 购买数量：宽横向浮层，保留商店背景；底层商店不能点击穿透。总量先做副本验证，确认一次只记一笔交易/撤销；库存或余额不足不部分扣款。
4. 暂停：气泡轮廓，继续/保存/图鉴/退出四项主按钮；额外功能缩到下面。设置恢复声音/亮度两条滑杆，结算复用气泡外形。
5. 图鉴：恢复左侧拼贴区、右侧名称/交互/规则区；去掉重复和串图的水母裁片白底。使用原素材和已有生物模型展示，没有新增游戏生物。
6. 引导：恢复蓝色圆角画框、深色演示区、下方翻页；用程序操作示意演示，不冒充正式视频。
7. 钓鱼：撤去大面积实色卡片，恢复上方细横条、左下圆环。保留原按住/松开的机制，圆环表示原收获进度。
8. 打开模态页或钓鱼时隐藏普通 HUD，关闭后恢复，避免文字和按钮重叠。
9. 接入 SourceHanSansCN Regular/Bold 与 Outfit Bold。修复动态字体 fallback 列表为空导致 Awake 提前中断、部分实时文字不显示的问题。

人物参考原图白底通过运行时 shader 处理，边缘仍可能有低清白边；正式透明人物替换后移除此临时处理。模型预览用于缺少独立图标的槽位；不会重做游戏模型或修改其动画。
