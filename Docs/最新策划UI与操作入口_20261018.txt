已接功能
- 关内保留原稿顶部任务带、右上菜单、底部提示。旧常驻调试参数/物种侧栏隐藏；背包 I、Esc 菜单、菜单内图鉴/设置/引导保持可达。靠近合法目标时，在目标旁显示 04 原始透明导出的 CLICK 气泡和 E / 点击提示，动作仍走既有 ApplyTool。
- 暂停四个主按钮不改；保存进度进入三槽管理。设置增加静音，维持声音/亮度两条滑杆，返回原来页面。
- 背包槽位点击先显示选中确认；按“手持 / 使用”才调用既有选工具或取出接口，不提前改变库存。仍按 TOOL / CREATURE / ITEM 三层排列，新增水母渔获数量。
- BUY / SOLD 飘带支持买入/出售切换，复用同一三行四列货架。正式航线只销售风箱、木箱、铲子、磁铁、发射器，空位保留。价格与解锁原因读取规则统一接口。
- 出售按普通鱼、虾、蟹壳、水母选择数量；不包含委托琉璃鱼。确认前预演，确认后一个事务/一个撤销，余额/数量/位置实时重验。
- 新手引导按首次出现记录 seenGuideKeys，保存在游戏状态、克隆和跨岛共享中；可跳过，关闭恢复原暂停状态。手动可翻阅 12 条，复用原稿画框。已有四类程序示意，其他用真实模型图标/文字示意，不冒充正式录屏。
- 结算气泡仍为原稿确认按钮；确认后出现策划的准备下一关/重试/回码头。下一关调用 PrepareNextCampaignIsland，仍须完成交付和老板交谈，不能直接越过锁定。
- 地图补第五正式关 index10，不改变原0—9旧存档索引。第五关复用“得不到的箱箱”原稿标题，旧荒岛显示其实际名称；按原稿保留两排透明标题牌、顶部红色居中出海、底部提示条，移除额外白卡和地图概览。分两页容纳新增岛；未解锁牌淡化并显示原因。
- 商店对话/通用确认页按策划气泡与确认线框配色绘制。按钮有轻微悬停放大、按下缩小，继续复用现有点击音。

存档实现
文件：HabitatGame.SaveSlots.cs。
公开 GetSaveSlotInfo(int)、SaveSession(int)、LoadSession(int)、DeleteSession(int)，槽号1—3。使用现有 Snapshot/RestoreSnapshot 与 WriteLatestSave 原子替换；保留 JSON 版本 HabitatIsland/1。
首次槽1可显示原 latest.json，不自动迁移/覆盖。保存到槽1后，该新槽优先；删除新槽1只删除所选文件，保留旧 latest.json，并写 slot-1.deleted 标记阻止列表自动复活。若槽1显示的正是旧文件，删除确认明确说明是原有存档。
列表显示共享 playSeconds 的真实“游戏时长”，由 HabitatPlayClock 记录，与生态暂停/加速无关；暂停、设置、存档、启动及其确认子页和失焦不累计，背包/图鉴/商店继续算活跃游玩。旧存档缺省为 0，不把旧 elapsed 冒充现实时间。
